Uso de REQUEST_INSTALL_PACKAGES

Safe Acuña puede descargar paquetes de actualización e iniciar el proceso de instalación de forma explícita cuando el usuario lo solicita.

La instalación siempre es iniciada por el usuario y requiere la confirmación mostrada por Android.

Cómo funciona

  • El usuario solicita una actualización.
  • La aplicación descarga el paquete correspondiente.
  • Android muestra la pantalla oficial de instalación.
  • El usuario decide si desea continuar o cancelar.

La aplicación no realiza instalaciones silenciosas ni modifica el sistema operativo. Todas las instalaciones requieren la acción y aprobación explícita del usuario.
